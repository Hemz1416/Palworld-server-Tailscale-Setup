================================================================================
           HEMZ TAILSCALE SERVER CONNECTION GUIDE (PALWORLD & MINECRAFT)
================================================================================

Welcome! This package allows you to connect securely to Hemz's hosted game
servers (Palworld & Minecraft Java) over Tailscale with zero port forwarding.

--------------------------------------------------------------------------------
OPTION A: 1-CLICK QUICK JOIN SCRIPT (RECOMMENDED & FASTEST)
--------------------------------------------------------------------------------
1. Double-click: Friend-Quick-Join.bat
2. If Tailscale is not installed, it will automatically download and install it.
3. Sign in to Tailscale in your browser (or accept Hemz's machine share link).
4. Select your game:
     [1] Palworld Dedicated Server (Port 8211)
     [2] Minecraft: Java Edition   (Port 25565)
5. The exact server IP & port is AUTOMATICALLY COPIED to your Windows clipboard!
6. Launch your game and press Ctrl+V to paste!

--------------------------------------------------------------------------------
OPTION B: GRAPHICAL CONNECTION APP
--------------------------------------------------------------------------------
1. Double-click: Hemz-Palworld-Connection-Setup.exe (or Tailscale-Connection-Setup.exe)
2. Follow on-screen status badges (Green = Ready).
3. Click [ CONNECT / COPY ADDRESS ] to copy address and launch game!

--------------------------------------------------------------------------------
IN-GAME JOIN STEPS:
--------------------------------------------------------------------------------
Palworld:
  Join Multiplayer Game -> Bottom IP address bar -> Paste (Ctrl+V) -> Connect

Minecraft (Java Edition):
  Multiplayer -> Direct Connection (or Add Server) -> Paste (Ctrl+V) -> Join Server

--------------------------------------------------------------------------------
NEED HELP:
--------------------------------------------------------------------------------
- Verify the Tailscale icon is running in your Windows system tray (bottom-right).
- If ping fails, ask Hemz to ensure the server is active in Host-Dashboard.bat.
